# Долговая яма

Учёт личных долгов в двух видах: геологический разрез «ямы» и реестр с диаграммой.

- **Разрез** — люди показаны слоями породы, толщина слоя равна сумме долга. Наведите или нажмите на слой, чтобы подсветить человека и вернуть ему деньги.
- **Реестр** — кольцевая диаграмма остатков, прогресс возвратов и таблица долгов и возвратов с поиском, редактированием и удалением.
- Все данные лежат только в `localStorage` браузера. При первом запуске загружается пример, который можно убрать одной кнопкой.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, предпросмотр: `npm run preview`.

Сделано на React + TypeScript + Vite. Графика — собственный SVG без сторонних библиотек.
